# Earthwing SR-71 browser lighting and exhaust (local only)

- Afterburner: an owned procedurally textured volume replaces the hard cone and repeated rings. The inner and outer volumes fade at the edges and taper downstream. Source anchors, independent per-engine ignition/shutdown behavior and ground clipping are unchanged. No downloaded textures or native effect graph are used. This is not native visual parity or a hardware performance benchmark.
- Cockpit: the emitters stay in the shader's light count while their intensity/emission changes. Owned cockpit light materials skip zero-color spots. An isolated software-rendered Chromium run recorded 12 new shader programs on first flood toggle before, 0 after. It does not establish the size of the hitch or frame rate on other machines.
- Aircraft exterior: **Controls / ? → SR-71 exterior lights** offers landing (`Shift+7`), taxi (`Shift+8`), tail/position (`Shift+9`), beacon (`Shift+5`), strobe (`Shift+6`). All bindings are editable in Settings. Landing and taxi use the original nose-gear fixtures and light only when the gear is fully down. No refuel-bay, wingtip-color system, or native electrical simulation is added. See `sr71-exterior-lights-local-review.md` for details.
- Airport runway illuminators are separate. Earthwing renders runway edges, ends, centreline/approach lights when applicable; dusk/night makes them easiest to see. PAPI remains visible by day. The aircraft landing switch does not control airport lights.
- Intermittent stray lines were not reproduced in the controlled fixed-camera exterior/cockpit checks under logarithmic or reversed depth. Scoped probe and limitations: `sr71-line-artifact-investigation.md`. No speculative render change was made for that report.

Run `npm test`, `npm run build`, and `SMOKE_AIRCRAFT=sr71 npm run test:smoke`. Targeted software WebGL checks: `node test/sr71-afterburner-fx-test.mjs --browser`, `node test/sr71-cockpit-lighting-browser.mjs`, and `node test/sr71-exterior-lights-test.mjs --browser` (these start only local isolated fixtures). No production deploy or claim of rights to publish third-party assets.
