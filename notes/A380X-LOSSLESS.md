# A380X lossless preview — archival instructions

This document describes a historical A380X preview, not the current DA40 edition. A380X is disabled in the current aircraft registry and picker; downloading the archived pack does not make it playable in this edition. Do not use its staging command to replace the current build or deployment.

The full 4K release has 4,224,711,914 bytes of converted model files. The player’s compressed pack takes 1,836,234,871 bytes, plus a 380,765-byte manifest. Gzip restores every original file by length and SHA-256 before Three.js parses it: 377 DDS textures and 1,194 source mip levels, 30 geometry buffers and 11 JSON/glTF files. No mesh simplification, resampling, texture downscaling, or additional GPU texture encoding. Models already in the game aren't changed.

The original full exterior is the sole aircraft startup model. It needs about 486 MB from a cold cache with the compressed preview; opening cockpit or passenger view requests the original combined interior later. The independently partitioned interior is opt-in research only: its full-resolution resource dependency graph passed, but pilot and passenger sightline equivalence has not been proven and it is not selected in this build. Transfer compression does not eliminate decompressed GPU residency; the original combined gameplay view remains unverified on the 16 GB software renderer.

To build the compressed-only staging tree from an already generated pack, run `node tools/a380-stage-lossless.mjs <pack directory>`. To generate an exact pack from the original raw assets, use `node tools/a380-lossless-pack.mjs public/models/a380x <pack directory>`; use an original-only source directory if working with optional partition descriptors. A release ZIP’s `node tools/fetch-a380x-lossless.mjs` instead fetches the verified staging pack directly, without needing to download the raw assets. The separately published full-detail previews are retained for browsers that don't support the native gzip path.
